# 購物記錄表助手

為學校買東西後，用來準備報銷文件的網頁工具。

上載淘寶訂單截圖、PPS 交易紀錄截圖和收據（相片或電子發票 PDF），工具會：

1. 讀出訂單編號、港幣金額、日期和商品名稱（用擴充功能截圖會直接讀頁面資料；其他截圖用文字辨識，全部在瀏覽器內進行）；
2. 一次購物（一筆 PPS 付款）可以包含幾張淘寶訂單、多件貨品，工具會按訂單編號和金額自動歸類；
3. 每 4 件貨品填一張「申請支票支付購物款項表格」，總款額是表內貨品的金額合計；
4. 在「收據配對」把每張收據對應到貨品（自動配對對不上時可以手動揀或拖放）；
5. 每張申請表後面附上表內貨品的淘寶訂單、收據，以及共用的 PPS 紀錄；
6. 直接列印或下載 A4 PDF。

網址：<https://edwardyungch.github.io/purchase-form/>

第一次打開後，程式和中文辨識資料會存在瀏覽器內，之後沒有網絡也可以用。電腦（Chrome / Edge）可以按網址列的「安裝」，iPhone 可以在 Safari 按「分享 → 加入主畫面」。

## Chrome 擴充功能「淘寶訂單截圖」

在淘寶「訂單詳情」頁按一下，就會只截取訂單範圍（不包括「猜你喜歡」和浮動工具列），長頁面會自動捲動拼接。訂單編號、實付港幣、每件貨品的標題、規格、價錢和數量會寫入圖片，上載到購物記錄表助手時不用文字辨識。

**安裝（只需做一次）**

1. 下載這個 repo（綠色 Code → Download ZIP）並解壓，或用 Claude 給你的 `extension` 壓縮檔。
2. 在 Chrome 網址列輸入 `chrome://extensions`，開右上角「開發人員模式」。
3. 按「載入未封裝項目」，揀 `extension` 資料夾。
4. 按工具列的拼圖圖示，把「淘寶訂單截圖」釘選出來。

**使用**

- 打開訂單詳情頁，按擴充功能圖示 →「截取這張訂單」，或按 `Alt+Shift+S`。
- 一次過開多個訂單詳情分頁，按「截取全部訂單分頁」，會逐個分頁截圖。
- 截圖存在「下載／淘寶訂單」資料夾，檔名是 `日期_訂單編號.png`。

擴充功能需要「讀取所有網站」權限，因為 Chrome 要有這個權限才可以截取未在前面的分頁；它只會在淘寶和天貓網頁上執行。

## 檔案

| 位置 | 內容 |
| --- | --- |
| `index.html` | 頁面及樣式 |
| `js/app.js` | 主程式（上載、配對、表格、排版、列印） |
| `js/parser.js` | 由辨識結果抽取訂單資料的規則 |
| `lang/chi_sim.traineddata` | 簡體中文辨識資料（tessdata_fast） |
| `vendor/` | 程式庫，由 GitHub Actions 自動下載（Tesseract.js、OpenCC、pdf.js、jsPDF、霞鶩文楷） |
| `sw.js` | 離線快取 |
| `extension/` | Chrome 擴充功能「淘寶訂單截圖」 |

設定（下拉選單選項、名稱詞典）只儲存在各部裝置的瀏覽器內，可以在「設定」匯出及匯入。
